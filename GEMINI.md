# Regras e Preferências do Projeto (Antigravity)

Utilizar o uv para gerenciar ambientes virtuais e bibliotecas, bem como executar scripts. 

## Instruções do Projeto
- Utilizar o uv para gerenciar ambientes virtuais e bibliotecas, bem como executar scripts. 

## Regra Crítica de Execução
- É terminantemente proibido utilizar ferramentas de terminal (como `uv run`, `python`, etc.) para executar scripts ou simulações sem que o usuário tenha expressamente autorizado.
- O fluxo OBRIGATÓRIO de ação é:
  1. Ler os dados e analisar o problema.
  2. Explicar a ideia de como a alteração será realizada.
  3. Editar os arquivos de código/dados solicitados.
  4. **PARAR E PERGUNTAR**: "A edição foi concluída. Posso executar o script para testar?"
  5. Aguardar a resposta afirmativa (autorização) do usuário antes de rodar qualquer comando de execução.
